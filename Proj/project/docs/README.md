## Research Paper

"Classifying Malware Families Using Graphlet-Based Topological Signatures from MalNet-Tiny"

This paper describes:
- Using ORCA to compute Graphlet Degree Vectors (GDVs)
- Extracting 2-, 3-, and 4-node graphlet features
- Computing Graphlet Correlation Matrices (GCMs)
- Using graphlet-based features for malware family classification
